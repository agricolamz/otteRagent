## `otteRagent`

Это пакет, который является набором инструментов для моего личного ассистента. Я сознательно нарушил несколько правил создния пакетов, так как не планирую отправлять пакет на CRAN:

- non-ASCII символы;
- переменные, которые определены в `.Rprofile`
  - `otteRagent_directory`
  - `otteRagent_preferred_out_mail`
  - `otteRagent_preferred_to_mail`
- бездумный набор зависимостей: я совершенно не ожидаю, что кто-то другой будет использовать этот пакет, поэтому в зависимости попадают все необходимые мне пакеты. Если кто-то вздумает ипользовать пакет у себя, я бы рекомендовал склонировать репозиторий, удалить ненужные функции и зависимости в файле `DESCRIPTION` и скомпилировать.

Все строится вокруг папки, путь к которой хранится в переменной `getOption("otteRagent_directory")`, где есть скрипт `otter_brain.R`, который запускается каждый час по `cron` (`Rscript ~/work/otter_space/otter_brain.R`). Скрипт можно запустить с аргуметом `DEBUG`, тогда логгер сообщит куда больше деталей о ходе исполнения. Вот мой текущий скрипт:

```
suppressPackageStartupMessages(library(tidyverse))
library(logger)
library(otteRagent)

args <- commandArgs(trailingOnly=TRUE)

if(length(args) == 0) {
  loglevel <- "INFO"
} else {
  loglevel <- args[[1]]
}

as.loglevel(loglevel) |>
  log_threshold()

appender_tee(file = paste0(getOption("otteRagent_directory"), "logs/logs.txt"),
             max_lines = 5000L,
             max_files = 10L) |>
  log_appender()

check_tasklist()
```

Функция `check_tasklist()` ожидает файл `tasks.csv` в папке, путь к которой хранится в переменной `getOption("otteRagent_directory")`, со следующими колонками:

- `id` --- id задачи
- `task` --- текстовое описание задачи (для логов)
- `skill` --- имя функции из пакета `otteRagent`
- `schedule` --- пока поле, которое может быть пустым (тогда правило будет повторятся каждый раз) или содержать `once` (тогда задача будет удалена, после выполнения)
- `ignore` --- если заполнено `ignore`, задача не исполняется
- `params` --- парамеры для заполнения аргументов функции.

Кроме того, в части функций предпологается привязка к аккаунту gmail через пакет `gmailr`.
