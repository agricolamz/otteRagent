## `otteRagent`

Это пакет, который является набором инструментов для моего личного ассистента. Я сознательно нарушил несколько правил создния пакетов, так как не планирую отправлять пакет на CRAN:

- non-ASCII символы;
- переменные, которые определены в `.Rprofile`
  - `otteRagent_directory`
  - `otteRagent_preferred_out_mail`
  - `otteRagent_preferred_to_mail`
- некоторые переменные, которые хранятся в предзаписанных датасетах
